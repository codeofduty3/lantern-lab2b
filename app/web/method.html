Reproduce every number

Run from the repository root after installing the environment.

dvc pull
dvc repro
PYTHONPATH=src python -m lookthrough.check
pytest -q
python scripts/export_app_data.py
  1. dvc pull restores the DVC-tracked release and pipeline inputs.
  2. dvc repro rebuilds the panel and reports in their declared dependency order.
  3. The self-check validates columns, reconciliation, admission, categories and provenance.
  4. The test suite covers the analytical pipeline and the read-only app.
  5. The exporter copies the verified values into compact app JSON without adding a DVC stage.
Analytical boundary

The panel supports a borrower-to-BDC relationship view. It does not claim cross-BDC matching, cross-period identity, or credit signals.
